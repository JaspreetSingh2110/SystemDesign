# System Design
A place holder for low level design framework implementation in C++ for various low level system design interview questions.
This project is created with aim to have low level design framework implementation for commonly asked low level design questions in system design interviews.

## Programming language: C++

## Contents
This project implements following low level system design:
* **Parking Lot**
* **Elevator System**
* **Library Management System**
* **Amazon Locker Service**
* **Vending Machine**
* **Online Blackjack Game**
* **Meeting Scheduler**
* **Movie Ticket Booking System**
* **Vehicle Rental System**
* **ATM System**
* **Online Chess Game**
* **Hotel Management System**
* **Amazon Online Shopping System**
  * **Stack Overflow**

### Class diagrams can be found [here](https://github.com/JaspreetSingh2110/SystemDesign/tree/main/ClassDigrams)
